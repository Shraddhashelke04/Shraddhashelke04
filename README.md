# Simple Python Project

This project demonstrates a minimal Python setup with a greeting script and a calculator module.

## Files

- `hello.py` – prints a greeting message.
- `calculator.py` – provides basic arithmetic functions: add, subtract, multiply, and divide.
- `tests/` – contains unit tests for the calculator module using `pytest`.
- `requirements.txt` – lists the project's Python dependencies.

## Setup

1. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Run the greeting script:

   ```bash
   python hello.py
   ```

3. Run tests:

   ```bash
   pytest
   ```
